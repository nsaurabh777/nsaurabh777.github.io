PythonPyPIAWS Secrets ManagerSageMaker Processing
Details →

Behind the work

A Streamlit application that reduces image-heavy PDFs to a target file size or custom DPI and JPEG quality while preserving document structure.

It helps users bring oversized PDFs under email and upload limits, with a PDFCompressor Python class for scripted workflows.
